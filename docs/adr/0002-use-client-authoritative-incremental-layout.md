# 使用客户端权威的增量布局引擎

流式简历排版由客户端 IncrementalResumeLayout 模块统一计算，使用稳定逻辑节点、实际字体测量、布局约束、最小差异和增量分页；服务端和 AI Agent 只产生逻辑内容操作，不计算像素级页面。选择这一方案是因为整页重建会破坏元素身份和并发编辑，而服务端复制字体环境会产生与画布和导出不一致的分页结果。

## Consequences

- 逻辑内容块是正文源数据，分页片段是派生结果。
- 后台 Solo 可以继续生成语义内容，但客户端重新连接后才能完成最终布局。
- 输入使用 RAF 局部预览，Worker 执行全局约束求解和分页，过期 revision 结果必须丢弃。
- 布局引擎只做有界密度优化，不删除或总结文字。
